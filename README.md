# NovaTrade — Stock Brokerage & Trading Platform

NovaTrade is a premium, data-dense, dark-mode fintech multi-page stock brokerage website built with plain HTML, CSS, and vanilla JavaScript.

## Features & Pages (9 Routes Total)

- **Home (`index.html`)**: Staggered hero animations, real-time simulated ticker, primary offerings, trust signals, and CTA.
- **Markets (`markets.html`)**: Dynamic instrument grid with interactive filtering across Equities, Derivatives, and Mutual Funds.
- **Instrument Detail (`instrument-detail.html`)**: Detailed asset view with interactive Chart.js price chart, timeframe selector, key fundamental stats, and live order panel.
- **Pricing (`pricing.html`)**: Transparent commission & brokerage plan tier comparison table (Standard, Pro, API).
- **About (`about.html`)**: Company story, mission, and regulatory compliance milestones.
- **Contact (`contact.html`)**: Accessible contact form with client-side validation and office location map placeholder.
- **Login (`login.html`)**: Centered authentication interface with client-side validation.
- **Register (`register.html`)**: Account creation with password confirmation & mandatory terms agreement.
- **404 (`404.html`)**: Custom error page.

## Tech Stack

- **HTML5**: Semantic markup with full accessibility standards (WCAG 2.1 AA).
- **CSS3**: Modern CSS variables, flexbox, CSS grid, dark theme by default with theme toggle persistence.
- **JavaScript (ES6+)**: Modular vanilla JS for interactive charts, market filtering, and form validations.
- **Icons**: Phosphor Icons library.
- **Favicon**: SVG favicon located in `assets/images/favicon.svg`.

## Getting Started

1. Clone or download the repository.
2. Open `index.html` in any modern web browser or serve using a static web server.

```bash
# Serve locally using Python
python -m http.server 8000
```
